# Sebo Encontro dos Rios
Sistema CRUD em Python via terminal para gerenciamento de acervo, vendas e relatórios do Sebo Encontro dos Rios

## Sobre o projeto

O Sebo Encontro dos Rios é um sistema de gerenciamento de acervo de livros usados, desenvolvido em Python como trabalho final da disciplina de Programação I.

O sistema tem como objetivo auxiliar no controle de livros, permitindo o gerenciamento do estoque, registro de vendas e consulta de informações por meio de uma interface de terminal.

## Objetivos do Projeto

- Organizar o acervo de livros.
- Facilitar o controle de estoque.
- Registrar vendas.
- Armazenar os dados de forma persistente.
